# UI 기준: IntelliJ Git 느낌

새 화면이나 기능을 만들 때 이 기준에 맞춘다. 테마 색은 Obsidian 변수를 쓰고, 구조와 조작만 IntelliJ를 따른다.

## 조작

| 키 | 동작 | 화면 |
|---|---|---|
| `F7` / `Shift+F7` | 다음·이전 변경. 끝에서 한 번 더 누르면 옆 파일로 | Diff |
| `Alt+←` / `Alt+→` | 이전·다음 파일 | Diff |
| `F4` | 노트 열기 | Diff, 변경 목록 |
| `F7` / `Shift+F7` | 다음·이전 미해결 영역 | 충돌 해결 |
| `↑` `↓` `Home` `End` | 행 이동 | 변경 목록, History |
| `←` `→` | 그룹 접기·펼치기, 상위 그룹으로 | 변경 목록 |
| `Space` | 체크 | 변경 목록 |
| `Enter`, `Ctrl+D` | Diff 열기 | 변경 목록 |
| `Ctrl+Alt+Z` | 변경 버리기 (확인 후) | 변경 목록 |
| `Ctrl+Enter` | 커밋 & 동기화 | 커밋 메시지 |

- 기본 전역 단축키는 넣지 않는다. `Ctrl+K`(링크 삽입), `Ctrl+T`(새 탭) 등이 Obsidian과 겹친다. 전역 조작은 명령으로 제공하고, 키는 사용자가 Obsidian 단축키 설정에서 정한다.
- 키는 해당 화면에 포커스가 있을 때만 동작한다. 한글 입력 상태에서도 동작하도록 문자 키는 `e.code`로 비교한다.

## 모양

- 행은 PC에서 24px로 촘촘하게, 툴바는 글자 없는 아이콘과 hover 상자로 만든다. 모바일은 터치 크기를 유지한다.
- 상태는 파일명 색으로 표시한다: 수정 파랑, 추가 초록, 삭제 회색 취소선, 충돌 빨강.
- Diff와 충돌 화면의 변경 블록도 같은 색을 쓴다: 수정 파랑, 추가 초록, 삭제 회색, 충돌 빨강. 바뀐 단어는 더 진하게 표시한다.
- 선택한 행은 옅은 파랑 바탕에 왼쪽 막대로 표시한다.

## 플랫폼

- 키보드 흐름, 커밋만 하기, 블록 되돌리기, History 분할 화면과 그래프는 PC 기능이다.
- iPhone은 지금처럼 터치 중심으로 두고, `↑` `↓` 버튼으로 같은 이동을 할 수 있게 한다.
- History는 폭이 640px 이상이고 모바일이 아닐 때만 분할 화면으로 보여 준다.

## 지켜야 할 규칙

- 아이콘 버튼에는 `aria-label`을 넣고, 키보드로 누를 수 있게 하며, 포커스는 `:focus-visible`로 보여 준다.
- 파일을 되돌리는 동작은 먼저 확인하고, 화면을 연 뒤 파일이 바뀌었으면 쓰지 않는다.
